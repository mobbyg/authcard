# Authcard
A simple website to generate authorization cards for voice RF comms.

Easy install.. just place the HTML file someplace, and load with your favorite browser.

Change the seed to generate new cards as you need. Keep the seed the same to recreate new cards for more people. 

Example of usage:
```
Station 1: "Station 2 this is Station 1, athenticate Alpha Romeo Echo."
Station 2: "Station 1 this is Station 2, I authenticate Hotel."
```
